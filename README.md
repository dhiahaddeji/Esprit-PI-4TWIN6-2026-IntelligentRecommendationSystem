## 🗄️ Database Setup

The project uses a **MongoDB Atlas cloud database** configured and deployed by me.

### Database Technology
- MongoDB Atlas (Cloud)
- Mongoose (NestJS ODM)

### Features
- Online shared database for team collaboration
- Secure authentication using database users
- Remote access for all team members
- Real-time data synchronization

### Architecture
React Frontend → NestJS API → MongoDB Atlas Cluster
